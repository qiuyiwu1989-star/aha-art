# 美学竞技场 · 论文构想（Research Concept）

> 工作中文档,非已投稿件。配套可读页面:`arena-paper.html`(从 arena-method.html 有入口)。
> 立项 2026-06-18 · 出品 浙江大学国际设计研究院

## 一句话定位
用一份「人类成对审美偏好」信号,同时驱动四件事——给图排名、给生成"做法"排名、给评审本身排名并回灌权重、给个体建审美画像;并把"评估劳动"反转为"照见自己"的动机闭环。

## 核心贡献（为什么不是"又一个图像 arena"）
既有 arena(LMSYS Chatbot Arena / GenAI Arena / 3D Arena / MEF 2025)已确立"成对投票 + Bradley-Terry + 置信区间"范式,**这不是卖点**。新意在四点叠加:
- **C1 做法层排名**:把图级胜负归并到生成 workflow/模型,排"哪种做法更出片",评估回流生产。
- **C2 评审元评估 + 加权聚合**:用"你选的那侧是否真在共识里更高"度量眼光(仅双方都比够时算),映成票权 `clamp(2·eye,0.5,2)` 回灌 BT。
- **C3 评估即个性化(双用)**:同一份偏好既产集体公榜,又反推个体审美画像/门派回馈本人,作为参与动机引擎。
- **C4 多轴分解 + 公平配对 + 人–AI 校准**:综合 / 去AI感 / 创意三轴;题材分层配对;人类共识校准 VLM 质量先验。

## 论文站位（三选一,推荐 A 为主线）
- **A（首推)HCI 系统论文**:覆盖整套系统,主张"一份评估信号的双用 + 自我发现维持参与"。→ CHI / CSCW / TiiS。
- **B 多媒体/评估-基准**:方法 + 公开偏好数据集(做法层 BT + 眼光加权 + 人–VLM 校准)。强依赖真实投票。→ NeurIPS Eval&Datasets / ACM MM。
- **C 推荐系统(小切片)**:12 维审美空间 + 倒U惊奇带 + 多峰 kNN/学维度权重 + 评估→画像桥。→ RecSys。

## 论文结构 Outline
1. Intro — arena 浪费了评审;论点:一份信号、四个产出 + 自我发现;贡献 C1–C4。
2. Related — arena 评估;美学质量评估;标注者质量/反作弊;审美推荐;游戏化众包。
3. System — 对决 UI(键盘/多轴镜头/收藏/放大)、结论卡、三榜、贡献榜、低唤醒设计。
4. Aggregation — BT(MM)+ 收缩 + bootstrap CI + 下界排序;做法层聚合(C1);两遍眼光加权 BT(C2);题材分层配对;多轴。
5. Bridge — 评估→个性化(C3):生成图 12 维 VLM 标注 → 口味向量/门派 → 推荐(多峰 kNN + 学维度权重)。
6. Human–AI — BT 共识 vs VLM quality(相关/散点);何时 AI 替人;校准先验(C4)。
7. Study — 部署 + 用户研究(下方)。
8. Discuss — 局限与伦理:冷启动、参数手调、数据规模、偏差、"给评审评级"的透明。

## 评估计划（实证骨架）
- 参与/留存:结论卡(自我发现)对场均场次/回访的影响(A/B 有/无结论卡)。
- 眼光加权抗噪:注入金标准对 + 随机乱投账号,验证加权 BT 比无权 BT 更稳。
- 做法榜效用:top 做法的产出在独立人评里是否真的更优。
- 人–AI 一致性:BT 共识与 VLM quality 相关、分歧样本分析。
- 桥的有效性:对决反推的口味向量预测后续 like 命中率(离线 + 在线 lift)。

## 诚实边界
生成图 12 维标注尚未全量;眼光加权/收缩参数部分手调;真实大规模投票数据尚需采集(冷启动用 AI 质量基线兜底)。**学术化第一步 = 上线采集 + 跑完标注桥(路线 A 冷启动 + E)。**
