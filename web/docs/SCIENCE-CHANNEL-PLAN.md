# 科学频道主页 · 规划（艺术背后的科学方法）

> 定位:把 `science.html` 从「诚实但干」的实验账本,升级成 aha 对外展示**科学/学术一面**的**可视化官方频道主页**。
> 一句话主张:**把每一幅画放进可测量的坐标系 —— 于是艺术第一次能被「结构化地比较」,并能被证伪。**
> 核心目标(科技感来源):不是“AI 讲艺术”,而是**一套把艺术拆成可比较坐标的测量手段**,且每个坐标都经过跨源实测与诚实分级。

状态:2026-06-18 起规划;`science.html` 账本版已上线,本计划是它的「可视化旗舰」升级。

## 三、要补做 / 重做实验的(诚实缺口)

1. **正交性量化(⑨ 的硬证据)** —— 现在“动机⊥情绪”只能肉眼看散点。**新增小实验**:算 corr(动机 one-hot, VAD) 与 R²(动机←VAD)≈0,用数字坐实正交,而非“看着像”。成本低,纯计算。
2. **评分者信度 ICC(已在 TODO,最关键)** —— 让多标注者 / VLM 对同一批画各打分,算 ICC≥0.7。这是把“一个人的眼光”变成“可复现测量”的唯一出口,也是循环性的真正解药。**学术可信度的最大单点提升。**
3. **扩样本·去西方偏置** —— 119 真迹 99.8% 西方。补东方样本再跑跨源相关,验证结论不是西画专属。
4. **(可选)风格→像素 重测** —— ④ 里 n=9 那条太弱,扩到更多挂作品的风格再测,要么变实要么诚实删。
