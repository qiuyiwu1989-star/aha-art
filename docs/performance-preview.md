## 当前实现

- 首页首批 24 件；接近底部自动以 keyset 查询下一批并追加到瀑布流。每次请求 24 件，保留已浏览的卡片；图片懒加载、屏外图片/画框卸载并保留测高占位，详情按作品锚点返回。轻量slot和元数据仍随实际浏览增长，尚未实现完整恒定内存虚拟列表。全馆统计独立渐进加载，不用当前页推算。
- 详情按 ID、馆藏码、旧 file 参数解析，只带目标作品与最多 12 件关联作品；七轴平均值独立按世界观查询。
- 世界观/情绪/艺术家/主题展/特展规则分页；游标绑定过滤条件；无全量 8000 回退。
- 展厅各逛法明确显示本页范围，不假装当前 24 件代表全馆分布。测试画册单独按需加载，优先固定测试代码；不足时按六区各 12 件补充。
- 统一 WebP/JPEG 缩略图与长边上限，原图不再自动失败回退。详情初始主图限制 1600px。
- 生命周期清理、框选 Set、滑杆维度去重、单次滚动恢复；后台去重及隐藏暂停；目录筛选取消/版本保护/重试；3D 隐藏时停止调度。
- SW 缓存排除失败和私有响应，容量/期限上限；共享 GET 状态检查、取消、超时、并发去重；写操作不重试。

## 交付边界

这是隔离预览实现，不是可直接覆盖服务器的发布包。入口仍反代到 18772，真实运行后端版本未完全定位；本适配器读取 122 存量数据库。需确认权威部署链后将数据契约迁入实际 API、验证功能，执行已授权的生产发布。不要把 `backend/remote_read.py` 或本地 HTTP server 直接当生产服务部署。

本地拒绝所有写接口；收藏、生成、登录和下单不接生产。真实个性化推荐与登录状态未验收。数据库索引未创建。

后续批次：其他 18 个旧页面迁移、图谱整包数据拆分、搜索/排序索引对照测试、真实弱网/手机指标与 20 次路由内存测试、服务容量治理。本次没有宣称全站计划完成。

全馆摘要冷读仍约 10 秒，已移出首屏关键链并缓存 5 分钟；不能把它当成已达成的高性能聚合。详情区域均值也按需获取。首次数据库读取经 SSH 冷请求约 1–3 秒，缓存命中更快，仍需实际 API 与索引优化。
