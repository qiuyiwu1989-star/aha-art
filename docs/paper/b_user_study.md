# b · 用户研究设计(测 serendipity / aha 率)

> **目的**:补离线指标看不见的东西——推荐到底有没有给用户「原来如此」的惊喜。这块数据能把短文撑成 IUI/CHI 全文,也是审稿人最想看的。
> **核心指标**:**Aha 率**(被标"原来如此"的推荐占比)、**接受率**、**熟悉↔惊喜两档对比**。

## 1. 研究问题(对应论文假设)
- **RQ1**:相比"最近邻(纯熟悉)"基线,我们的「惊喜档」是否带来**更高的 aha/惊喜感**而**不显著牺牲喜欢度**?
- **RQ2**:用户能否感知并善用「熟悉↔惊喜」旋钮?不同人是否稳定偏好不同档位(印证"一致 vs 探索"二分)?
- **RQ3**:冷启动**置信门控**(诚实标"初步")是否提升信任、而不降低使用意愿?

## 2. 设计概览
- **被试**:N = 24–30(目标 30),覆盖艺术素养高/低各半;校园+社交招募。
- **设计**:被试内(within-subject),三种推荐条件**盲测、顺序平衡(拉丁方)**:
  - **C1 熟悉**(ex≈0.2,≈最近邻)· **C2 惊喜**(ex≈0.8,倒U)· **C3 随机**(对照)。
- **流程**(约 15–20 分钟):
  1. **校准**:逛 12–15 幅做二选一/心动,长出初步 μ(到"成形中")。
  2. **三轮评分**:每条件呈现 10 幅推荐,逐幅评(见 §3 量表)。
  3. **旋钮探索**:开放「熟悉↔惊喜」滑块自由调 5 分钟,记录停留档位 + 主观说明。
  4. **退出问卷 + 简短访谈**(3 题,见 §5)。
- **伦理**:走 co-author 单位 IRB;匿名、可随时退出、无对错、数据仅研究用(沿用产品里已有的诚实文案)。

## 3. 单幅评分量表(每条推荐都问)
| 维度 | 题面 | 量表 |
|---|---|---|
| **喜欢度 Liking** | 我喜欢这幅画 | 1–7 |
| **熟悉度 Familiarity** | 这幅画很像我平时会喜欢的 | 1–7 |
| **惊喜/顿悟 Aha**(★) | 这幅画让我"原来如此/没想到还有这种" | 1–7 |
| **可理解 Graspable** | 我能 get 到它好在哪(不是看不懂) | 1–7 |
| 二元标记 | □ 我会收藏它　□ 跳过 | 勾选 |

> **Aha 率** = (Aha≥5 的推荐数) / 总推荐数;serendipity 常被定义为 **unexpected ∧ relevant** → 用 **Aha≥5 且 Liking≥5** 作"有效惊喜"复合指标。

## 4. 量化分析(对应 RQ)
- **RQ1**:三条件在 Aha / Liking / 有效惊喜上的均值差异 —— 重复测量 ANOVA 或混合线性模型(被试为随机效应),报效应量。**预期**:C2 惊喜档 Aha 显著高于 C1/C3,Liking 与 C1 无显著差(不牺牲喜欢)。
- **RQ2**:旋钮停留档位的分布是否**双峰/个体稳定**;把每人停留档位与其离线 d* / spread 相关 → 印证"一致 vs 探索"。
- **RQ3**:门控组(显示"初步·成熟度")vs 不显示组的**信任量表 + 继续使用意愿**(可作小被试间附加因子)。

## 5. 退出问卷 + 访谈
- 量表:整体满意(1–7)、信任(1–7)、"愿意每天来看推荐"(1–7)、SUS 简版(可选)。
- 访谈 3 题:① 哪幅最"原来如此"?为什么?② 你更想要"更像你爱的"还是"多点意外"?③ 看到"档案还在成形/初步"时你的感受?
- 开放反馈一栏。

## 6. 落地与采集
- **可直接用现有系统跑**:C1/C2 = `foryou?w_aha=0.2 / 0.8`;C3 = random 策略(评估台里已有)。
- 加一个极薄的**实验采集页**(或复用 me.html 的"为你推荐"+ 量表浮层),把每幅评分写入 `mu_study` 表(uid, cond, work_id, liking, familiarity, aha, graspable, collected, ts)。
- 同时**自动记 rec_lift**(曝光→后续行为),线上行为与主观量表交叉验证。

## 7. 写进论文(§6 用户研究小节 + Fig 4)
- 一张分组柱状图(三条件 × Aha/Liking,带误差棒)= **Fig 4**;一句话结论模板:
  > "惊喜档在 Aha 上显著高于熟悉档(Δ=…, p<…),而 Liking 无显著下降——说明倒U 带来的不是『更准』而是『更值得』,印证准确率指标遗漏了 serendipity 的价值。"
