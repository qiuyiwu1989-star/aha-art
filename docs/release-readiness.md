# 发布准备与性能门禁

当前为本地 8766 验证分支，不是生产发布包。禁止直接部署 serve.py 或通过 SSH 查询的 remote_read 适配器。生产入口已知反代 18772，但仍需核实实际进程、代码版本、数据库权限、迁移负责人及回滚入口。

## 可重复门禁

运行 `python3 scripts/performance_gate.py`：新页面出现大 limit 请求失败；现有例外数量增加失败；新增 >1 MiB JSON 包或已登记大包增长失败。例外仅是已知债务，不是批准继续扩大。门禁是静态字面量检查，不能发现变量拼接请求，也不等价于实测性能验收。

当前无大 limit 静态例外：dashboard 已接入 frame-catalog 分页，并通过原 AHAFrames 规则引擎计算全馆统计。正式后端仍需接入这些数据契约。特展已用规则聚合；档案已按实际键 resolve；3D 已用各世界观代表作品，均已移除大 limit。

静态包登记：artworks_v2 12,467,108 B（完整原始来源仍保留，活页详情已迁为分片）；points 8,351,942 B；affect 7,877,182 B；artworks_index 1,421,218 B。图谱点位与情绪总览仍依赖全局几何/分布，下一步要由服务提供聚合概览与视口查询，不可删除部分数据冒充全局。

## 发布前必须补齐

- 登录、退出、跨页登录态、收藏读写：本地拒绝写入，真实账号流程未验证。
- 后台保存、上下架、策展、讲解管理：未对生产执行写操作；需隔离测试环境及数据恢复机制验证。
- SW：本机 127.0.0.1 未注册，现有行为模拟测试不覆盖真实升级、离线、旧缓存清理。
- 真机：浏览器窄屏验证不代表 iOS/Android 真机与低内存、弱网；需实测滚动、详情返回、解码、页面隐藏恢复。
- 容量：无生产并发压力测试；SSH 预览请求时间不能当正式 API SLA。需实际 API 查询计划、连接池、超时、速率限制与监测。
- 静态发布：分片与页面原子更新，明确缓存版本/失效策略；验证旧页面与缺片错误恢复。保留前一版静态目录与后端版本以便回滚。
