# 2026-10-25 首页瀑布流修订

用户明确要求：首页不断下拉自动加载，所有设计严格沿用既有 AHA 样式。

实现：移除首页上一页/下一页；底部进入视口前 700px 时加载下一批 24 件，追加现有最短列；保留已浏览作品与位置。不在启动时获取完整馆藏。

并发与错误：加载中不会重复请求，同 ID 去重；失败停止自动重试，展示现有 moreBtn 样式的重试按钮；末页停止；路由离开取消请求并断开观察器；首页初始数组独立复制，防止追加污染 HOME 缓存游标。

设计：读取 design-system.html、aha-kit.css、aha.css。美术馆保留其暖墙、字体、画框、列间距，状态复用 moreDone / moreBtn。移动端标题与数量不挤断行，说明独占下一行。全站风格约束写入 AGENTS.md，未对其他页面做未经请求的视觉重制。

验证：语法检查通过。执行真实瀑布流闭包的测试覆盖自动触发前零请求、重复触发合并、追加/去重、失败显式重试、游标推进、末页停止、路由清理。浏览器下拉后 24 → 48 张，首件仍为 Woman selling decorative bowls；无分页按钮，画框和双列瀑布流保持原样。

性能边界：每次只传24件，图片懒加载；屏外卡片 content-visibility:auto，并按图片比例提供高度估计。DOM 随实际浏览数量增长，本次没有声称已实现完整虚拟列表。后续长时间浏览内存优化必须保留连续下拉体验。

仅本地 8766 生效，未部署线上。
