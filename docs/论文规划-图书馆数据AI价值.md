# 论文规划 ·《图书馆数据在 AI 时代如何发挥价值》

> 以 aha 人类美术馆项目(浙大图书馆供数)为案例,面向图书情报同行,讲数据治理→可视化→激活的 AI 实践。
> 本文是**选刊 + 写法**的规划,不是论文本身。

## 一、定位:这是一篇什么论文

**不是**项目/产品宣传,**是**一篇"案例研究 + 可迁移方法框架"的实践探索型论文。
图书情报期刊录用的关键,不在于"我们做了个酷东西",而在于:
- 提炼出**别的馆能照着做**的方法论/框架(理论贡献);
- 用**真实数据 + 诚实的教训**支撑(可信度);
- 回应一个**学界关心的真问题**(图书馆海量数字资源长期"藏而不用"的沉睡困境)。

**核心论点(立意,一句话)**:
> 在 AI(尤其多模态大模型)时代,图书馆数据的价值实现路径正从"**保存与检索**"跃迁为"**治理→知识化→激活**"——馆藏由静态档案变为可被机器理解、可视化呈现、可个性化生成的**活的知识资产**。

这条主线同时勾住两个政策热词,审稿人会买账:
- **数据要素 / 数据资产入表**:图书馆数据如何从"成本"变"资产";
- **新质生产力 / 大模型赋能 GLAM**(图书馆-档案馆-博物馆)。

## 三、Q2:怎么写比较好

### 3.1 提一个框架(论文的"理论贡献"骨架)
把全部工作收进一个**三阶段价值化模型**,让文章不止是"我们做了什么",而是给同行一把可复用的尺子:

> **治理(可信)→ 知识化/可视化(可见)→ 激活(可用)**
> ——对应 DIKW 的升级:Data → Information → Knowledge → **Wisdom/个性化生成**。

- **① 数据治理(让数据可信)**:多源汇聚、去重、质量闸、规范化——把"脏、散、重"的原始数据变成可信资产。
- **② 知识化与可视化(让数据可见)**:VLM 多维标注、知识图谱、世界观坐标/情绪坐标等可视化——让数据可被理解、可被看见。
- **③ 数据激活(让数据产生价值)**:个性化推荐、千人千面画像、生成式再创作——让沉睡馆藏变成持续产生价值的活资产。

### 3.2 建议章节结构(实践探索型,6-7 节)
1. **引言**:数字馆藏"藏而不用"的沉睡困境 + AI 转机 → 研究问题与贡献。
2. **相关研究**:智慧图书馆、数据治理/数据资产、数字人文、大模型/多模态在 GLAM 的应用。
3. **案例与总体框架**:介绍 aha 案例;提出"治理→知识化→激活"三阶段模型(图)。
4. **方法与过程**(本文重心,对应你的三块):
   - 治理:多源入库适配、sha256+感知哈希去重(实证:某批 ~74% 为重复)、分辨率与质量闸、规范化标准。
   - 知识化:VLM 六维标注流水线(媒介/题材/风格/阅读动线/构成/情绪)、知识图谱五层、向量化。
   - 激活:核心资产画廊、单画富可视化解读、12 维审美档案与个性化推荐、生成式再创作。
5. **成效**:数据规模与质量(可信指标)、新的使用方式与用户价值(可用指标)、可视化呈现实例(配图)。
6. **讨论与经验(最有价值的一节)**:
   - **可迁移的方法论**:其他馆如何照做;
   - **诚实的教训**:VLM"认作者"高置信仍 ~85% 错→不可盲信、需人工校验(AI 幻觉治理);低分辨率名画缩略图 VLM 给高分但不可用→需客观分辨率闸;去重的必要性;算力/成本权衡;
   - **伦理与版权**:公共领域/CC0 边界、AI 标注的不确定性与"诚实标注"原则。
7. **结论与展望**:图书馆从"保存者"到"知识激活者"的角色转型。

### 3.3 写作要领
- **用真实数字当证据**,别空谈:数据总量、去重比例、过闸通过率、分辨率阈值、推荐契合度、艺术家中英文考据覆盖等。
- **诚实是最大的学术信用**:把"VLM 幻觉""筛掉的低质""做错又撤回的实验"写进去,反而比报喜更可信,也更对同行有用。
- **弱化商业/产品语气**,强化**公共文化价值 + 方法可复制 + 对同行的启示**。
- **图要讲故事**:三阶段框架图、流水线图、世界观/情绪可视化截图、推荐前后对比——图情期刊重视可视化呈现。
- **摘要写成"问题—方法—发现—启示"四段式**;关键词覆盖:智慧图书馆、数据治理、数字人文、大语言模型/多模态、知识组织、数据资产。
- **挂政策与时代背景**(引言/结论各一处):数据要素、新质生产力、数字中国、大模型赋能。

### 3.4 一句话摘要(草稿,供打磨)
> 面向数字馆藏长期"藏而不用"的困境,本文以浙江大学图书馆参与供数的"人类美术馆"项目为案例,提出"治理—知识化—激活"三阶段数据价值化框架,系统阐述多源去重与质量治理、多模态大模型标注与知识图谱构建、个性化推荐与生成式再创作的方法与过程,并坦陈 AI 标注幻觉、低质数据过滤、算力成本等实践教训,为 AI 时代图书馆数据资产的价值释放提供可迁移的路径参考。
